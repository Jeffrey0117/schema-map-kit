# schema-map-kit

**資料庫結構地圖:從 Supabase/PostgREST 或 SQLite 產出「表名 + 欄位: 型別」文字清單、抽樣 json key 與狀態值、包成可搜尋的單頁網頁。零依賴 CLI,附資料設計守則。** 零依賴、框架無關。

## 安裝

```bash
npm i github:Jeffrey0117/schema-map-kit   # 或直接複製 index.js
```

## 用法

```js
const create = require('schema-map-kit');
const x = create({ /* opts */ });
```
